# YvL Racks — 3D Portfolio

A Vite + React portfolio with Three.js / React Three Fiber, Framer Motion, and Tailwind CSS.

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

Deploy the project directly to Vercel or Netlify; both detect Vite automatically.

## Customize
- Edit project content in `src/main.jsx`.
- Edit visual styling in `src/styles.css`.
- The contact form is intentionally frontend-only; connect its `onSubmit` handler to Formspree, Resend, a serverless function, or your preferred backend before production use.
